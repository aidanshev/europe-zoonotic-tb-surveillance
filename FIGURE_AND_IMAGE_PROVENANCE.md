# Figure and image provenance

**No raw third-party pictures, report screenshots, photographs, microscopy images, or externally sourced figure binaries are included.**

Manuscript analytical figures should be regenerated from code and publication-safe aggregate plotting data. If an external visual is referenced, cite/link its originating site instead of copying the binary unless redistribution rights are independently confirmed.

## Relevant source sites
- **EFSA/ECDC EU One Health 2024 Zoonoses Report:** https://www.efsa.europa.eu/en/plain-language-summary/european-union-one-health-2024-zoonoses-report
- **EFSA biological monitoring of zoonoses:** https://www.efsa.europa.eu/en/data-report/biological-monitoring-zoonoses
- **WHO Tuberculosis Data:** https://www.who.int/teams/global-tuberculosis-programme/data/

## Generated figures
Project-generated plots are analytical outputs. Their underlying data provenance is recorded in `DATA_SOURCES.md`. Generated maps should cite the boundary provider.

The release audit intentionally fails if common image-binary extensions are committed.
